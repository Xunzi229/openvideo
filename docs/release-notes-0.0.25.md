## 更新亮点

- 新增 **设置 → 通用配置 → 播放屏幕方向**，支持“默认 / 竖屏 / 横屏”。默认保留原有自动方向逻辑；选择竖屏或横屏后，打开视频及切换下一条视频均按所选方向开始播放，播放中仍可手动切换方向。
- 新增 **设置 → 通用配置 → 本地继续播放位置**，支持显示在页面上方或下方。底部显示时为继续播放栏预留空间，最后一项可以完整滚动到栏位上方。
- 修复 Android 9 本地媒体库在已授予存储权限后仍无法刷新的兼容性问题。

## 播放与字幕修复

- 优化播放器缓冲停滞的错误提示，提供兼容播放入口并保留当前播放位置；补全最近播放状态、跳转、媒体格式及解码器诊断，便于定位远程用户反馈。
- 修复播放会话切换、后台恢复时的状态处理，避免过期的字幕加载结果覆盖当前视频，改善主副字幕及音轨恢复。
- 优化进度预览缩略图的提取与位图处理，减少相关异常。
- 改善外部字幕文档访问、编码识别及异常处理，完善媒体导出与播放历史关联。

## 界面与稳定性

- 隐藏尚未实现功能的播放器 TV 按钮。
- 统一同类设置选项弹窗的文字居中显示。
- 修复应用升级后更新提示红点未正确清除的问题。
- 改善 WebDAV 目录解析、缓存容量控制及网络异常分类，减少无效重试与缓存增长。

## 安装说明

- 普通 Android 手机优先选择 `arm64-v8a`；不确定设备架构时选择 `universal`。
- 同时提供 `armeabi-v7a`、`x86`、`x86_64` 安装包和 `SHA256SUMS.txt` 校验文件。
- 所有安装包使用与既有正式版本一致的 Release 签名，支持覆盖升级。

## 验证与已知限制

- 本次功能改动已通过 1,643 项本地单元及回归测试，Lint 与 Release 构建通过。
- 已在 Mi 10 Pro 验证方向配置、竖屏视频横屏播放、手动切换方向和切换视频时恢复配置。
- Android 9 媒体库修复已通过对应系统媒体表的自动化回归，仍需原反馈设备确认实际扫描结果。
- 缓冲停滞处理改善了错误恢复入口与诊断；个别 AVI 文件是否可正常播放仍取决于文件内容及设备解码能力。
