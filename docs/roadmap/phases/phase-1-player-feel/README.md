# Phase 1：播放器手感升级

**建议周期：** 2～4 周  
**目标版本：** v0.2.0 播放手感版  
**阶段目标：** 对齐 MX Player、Just Player、mpv-android 等高频播放体验，把现有「功能齐」推进到「手感稳定、操作顺滑、反馈清晰」。

---

## 1. 成功定义

1. 支持捏合缩放、拖动画面、双击恢复，并与现有比例、旋转、镜像、取景框策略不冲突。
2. Seek 拖动支持缩略图预览 MVP，低端机可关闭，性能有节流和缓存策略。
3. 字幕位置、字号、延迟可以在播放页快速调整，有即时 HUD 和持久化。
4. 耳机/蓝牙断连、音频同步、后台/通知控制体验更可靠。
5. 播放页首次使用有轻量手势教程，降低功能发现成本。

---

## 2. 非目标

| 不做 | 原因 |
|------|------|
| 不做完整视频编辑器 | 片段导出已有基础，本阶段聚焦播放手感 |
| 不做高级插帧/超分 | 成本高、设备差异大、偏离短期目标 |
| 不做全量 ASS 特效 | 字幕高级样式留给 Phase 4 |
| 不做 Android TV 深度遥控 | 大屏/遥控留给 Phase 5 |
| 不默认开启重型预览缓存 | 避免低端设备卡顿和存储膨胀 |

---

## 3. 工作流拆分

| 工作流 | 目标 | 主要模块 | 关键风险 |
|--------|------|----------|----------|
| Zoom/Pan | 捏合缩放与平移 | `PlayerZoomPanPolicy`、`PlayerActivity`、布局变换 | 与 `AspectRatioFrameLayout`、旋转、镜像冲突 |
| Seek Preview | 进度拖动预览帧 | `PlayerSeekPreviewExtractor`、缓存、HUD | 抽帧耗时、内存、不同 URI 权限 |
| Subtitle Gestures | 字幕快捷调整 | 字幕 presentation policy、HUD、Prefs | 手势冲突、误触、竖屏空间不足 |
| Audio Device | 耳机/蓝牙策略 | Audio becoming noisy receiver、player policy | 生命周期和权限差异 |
| Tutorial | 播放页教学 | onboarding/overlay、Prefs | 打扰老用户 |

---

## 4. Sprint 节奏

### Sprint 1.1：Zoom/Pan 策略模型（3～4 天）

| 切片 | 任务 | 交付物 | 验收 |
|------|------|--------|------|
| 1.1.1 | 定义缩放状态 | `PlayerZoomPanState(scale, offsetX, offsetY, sourceSize, viewportSize)` | 单元测试覆盖默认、缩放、重置 |
| 1.1.2 | 边界计算策略 | 缩放后拖动不能露出非法黑边，支持居中回弹 | 测试覆盖 16:9、9:16、4:3、超宽屏 |
| 1.1.3 | 手势冲突表 | 明确单指/双指、横向 seek、边缘返回、锁屏状态优先级 | 文档和测试固定规则 |
| 1.1.4 | 与画面设置联动 | 比例、旋转、镜像、ContentFrameMode 切换时重算或重置 | 不出现累计错位 |
| 1.1.5 | 持久化策略 | 默认不跨视频持久化，仅保留当前播放会话；可选每视频记忆后置 | 退出重进符合预期 |

**建议优先级：** 先做纯函数策略和测试，再接 UI 手势。

### Sprint 1.2：Zoom/Pan UI 接入（3～5 天）

| 切片 | 任务 | 交付物 | 验收 |
|------|------|--------|------|
| 1.2.1 | ScaleGestureDetector 接入 | 双指捏合缩放 | 不影响单指亮度/音量/seek |
| 1.2.2 | 平移接入 | 缩放 > 1 时单指拖动画面，未缩放时保留原手势 | 锁屏时禁用或只允许显示锁控件 |
| 1.2.3 | 双击策略调整 | 双击播放/暂停与双击恢复缩放的优先级明确 | 用户设置仍生效 |
| 1.2.4 | HUD 反馈 | 显示 `120%`、`已恢复默认画面` 等短提示 | HUD 不遮挡字幕核心区域 |
| 1.2.5 | 快捷重置入口 | 设置面板/快捷菜单增加恢复画面 | 所有变换一次恢复默认 |

**真机检查：** 横屏、竖屏、锁屏、PiP 进入/退出、旋转、镜像、不同宽高比视频。

### Sprint 1.3：Seek 缩略图预览 MVP（4～6 天）

| 切片 | 任务 | 交付物 | 验收 |
|------|------|--------|------|
| 1.3.1 | 抽帧技术选型 | `MediaMetadataRetriever` vs ExoPlayer frame grab 可行性记录 | 明确本地文件优先、网络后置 |
| 1.3.2 | 缩略图缓存模型 | 内存 LRU + 磁盘可选；按 video identity / uri + time bucket | 缓存可清理 |
| 1.3.3 | 节流策略 | 拖动时每 200～300ms 抽一帧或命中缓存 | 快速拖动不卡 UI |
| 1.3.4 | 预览 HUD | 横屏/竖屏不同位置，显示时间与预览图 | 不遮挡手指和字幕 |
| 1.3.5 | 设置开关 | 默认开启或按设备保守开启，提供关闭 | 低端机可规避卡顿 |
| 1.3.6 | 失败降级 | 抽帧失败只显示时间，不影响 seek | 不崩溃、不阻塞播放 |

**性能指标建议：** 单次抽帧不在主线程；连续拖动期间 dropped frames 不明显；缓存上限可配置。

### Sprint 1.4：字幕快捷手感（3～5 天）

| 切片 | 任务 | 交付物 | 验收 |
|------|------|--------|------|
| 1.4.1 | 字幕 HUD 状态模型 | 字号、位置、延迟、开关状态 | 单元测试覆盖边界值 |
| 1.4.2 | 快捷面板增强 | 字幕延迟 ±500ms、位置上/下、字号 ± | 点击后即时预览 |
| 1.4.3 | 字幕手势开关 | 默认关闭或保守，设置中可开启 | 不破坏亮度/音量手势 |
| 1.4.4 | 字幕位置安全区 | 避免与底栏、手势 HUD、系统导航条重叠 | 横竖屏均可读 |
| 1.4.5 | 记忆策略 | 全局默认 + 每视频覆盖的边界设计 | 不意外污染其他视频 |

### Sprint 1.5：耳机/蓝牙与播放页教程（2～4 天）

| 切片 | 任务 | 交付物 | 验收 |
|------|------|--------|------|
| 1.5.1 | 耳机拔出暂停 | 监听 AudioManager noisy intent | 外放切换时暂停并提示 |
| 1.5.2 | 蓝牙延迟入口 | 音频延迟快捷入口更明显 | 用户可快速调 ±50/±100/±500ms |
| 1.5.3 | 后台恢复一致性 | 从通知/蓝牙恢复时同步播放页按钮 | 状态不反转 |
| 1.5.4 | 手势教程 overlay | 首次进入播放页展示 3～5 个核心手势 | 可跳过，不重复打扰 |
| 1.5.5 | 教程重看入口 | 设置页或播放器设置里可重看 | 新手引导可复用 |

## 5. 手势优先级规则

| 状态 | 双指 | 单指横向 | 单指左侧纵向 | 单指右侧纵向 | 双击 | 长按 |
|------|------|----------|--------------|--------------|------|------|
| 未锁屏、未缩放 | 缩放 | seek | 亮度/用户配置 | 音量/用户配置 | 用户配置 | 倍速/用户配置 |
| 未锁屏、已缩放 | 缩放 | 平移优先，边界后可 seek | 平移优先 | 平移优先 | 恢复缩放或用户配置 | 倍速 |
| 锁屏 | 禁用或只显示提示 | 禁用 | 禁用 | 禁用 | 显示锁控件 | 禁用 |
| PiP | 系统接管 | 系统接管 | 系统接管 | 系统接管 | 系统接管 | 系统接管 |

## 7. 验收清单

- [ ] 缩放/平移与亮度、音量、seek、锁屏、PiP 不冲突。
- [ ] 画面恢复默认在所有方向/比例/镜像/旋转组合下可用。
- [ ] Seek 缩略图失败可降级为纯时间预览。
- [ ] 字幕位置/字号/延迟调整即时生效且可持久化。
- [ ] 拔出耳机暂停，不影响蓝牙/通知控制状态同步。
- [ ] 首次播放教程可跳过、可关闭、可重看。
