# Phase 6：品牌、发布与增长

**建议周期：** 并行推进，贯穿 v0.1.0～公开发布版  
**目标版本：** 公开发布版  
**阶段目标：** 让 OpenVideo 从个人可用工具走向可公开分发的产品：品牌清晰、隐私可信、新手友好、发布流程稳定、反馈闭环顺畅。

---

## 1. 成功定义

1. 用户第一次打开应用能理解：为什么要权限、如何扫描、如何播放、有哪些核心手势。
2. 应用有统一品牌视觉：图标、启动页、空状态、README/商店截图、Release 素材。
3. 隐私说明清晰解释本地扫描、网络请求、崩溃上报、设置导出、在线字幕等行为。
4. GitHub Release、Obtainium、F-Droid 可行性路径明确。
5. 用户遇到问题时能导出脱敏诊断并快速提交 Issue。

---

## 2. 非目标

| 不做 | 原因 |
|------|------|
| 不做商业增长/广告 | 与无广告、隐私友好定位冲突 |
| 不强制登录 | 公开发布初期不引入账号复杂度 |
| 不做复杂官网 | README + Release + 简单落地页足够 |
| 不追求一次性全渠道上线 | 先 GitHub Release，再评估 F-Droid/Obtainium |
| 不做遥测默认开启 | 崩溃/反馈必须透明可控 |

---

## 3. 品牌定位

### 3.1 一句话

OpenVideo：好看、无广告、隐私友好的 Android 本地视频播放器。

### 3.2 关键词

| 关键词 | 表达 |
|--------|------|
| 干净 | 无广告、无信息流、无强制账号 |
| 好看 | 现代深色 UI、玻璃感播放器、精致空状态 |
| 强大 | 字幕、音轨、手势、媒体库、多来源 |
| 私密 | 本地优先、权限透明、诊断脱敏 |
| 开放 | 开源、Release 清晰、社区反馈 |

## 6. 隐私说明必须覆盖

1. 媒体权限：只用于扫描本机视频。
2. 通知权限：只用于后台播放控制。
3. 网络权限：用于检查更新、未来 URL/WebDAV/在线字幕，具体功能触发时说明。
4. 崩溃日志：是否远程发送、发送哪些字段、如何关闭。
5. 设置导出：默认不包含密码、token、隐私文件夹完整路径。
6. WebDAV/网络来源：凭据如何保存、如何删除。
7. 在线字幕：搜索时会发送哪些标题/语言/集数信息。
