## 6. 遥控验收路径

1. 启动应用。
2. 授权或跳过授权说明。
3. 进入继续观看。
4. 打开某个剧集详情。
5. 选择一集播放。
6. 播放/暂停。
7. 快进 10 秒。
8. 打开字幕面板并切换字幕。
9. 打开音轨面板并切换音轨。
