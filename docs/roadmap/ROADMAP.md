### Wave 3 — P9-1b 高级画面取景（变焦 / 取景框）

**状态：手动 pinch/pan + R-04 智能裁边 POC Done — P1（后续为算法抛光 / 回归资产）**

- 预设居中条带（16:9 / 4:3）、`PlayerContentFramePolicy` 变换、显示设置 UI、历史持久化已落盘。
- 手动 pinch 缩放（1x～4x）、缩放后单指平移、双击恢复；与 FIT/16:9/4:3 及 P9-1b 条带变换叠加；切歌与非 FIT 比例时自动复位。
- R-04 智能裁边 POC 已落盘：横屏右侧快捷按钮触发，先隐藏控制层，再优先从视频 render view 取非黑内容包围盒，失败时退回最终 `PlayerView` 截图；只有上下左右四边都存在黑边时才等比例放大，目标画面约占视口 88%，不铺满全屏，不做非等比裁切。
- 裁边是 session-only：退出/重进视频不自动恢复上次裁边，不读取 `playerPrefs.contentFrameMode` 当作智能裁边状态；再次点击按钮关闭当前裁边会话。
- 实现约束与防回归准则见 [`智能裁边实现说明.md`](../智能裁边实现说明.md)。
